
# 🎓 College Event Hub – Event Management System

## 📌 Project Description
College Event Hub is a responsive web-based Event Management System developed using HTML, CSS, and JavaScript. It helps students explore college events, view event details, register for events, and manage their registrations through a simple and user-friendly interface.

The project demonstrates frontend web development concepts, dynamic content rendering, form validation, event handling, and browser-based data storage.

## 🎯 Problem Statement
Managing college events manually can be time-consuming. Students may find it difficult to discover events, check schedules, register, and track their participation. This project provides a simple digital platform to make these activities easier.

## 🎯 Objectives
- Display college events dynamically.
- Allow students to search and filter events.
- Show event dates, venues, categories, and descriptions.
- Provide a student registration form.
- Validate required fields and email format.
- Prevent duplicate registrations for the same event.
- Track registrations and event capacity.
- Allow students to view and cancel registrations.
- Store registration data using Local Storage.

## ✨ Key Features

### 1. Dynamic Event Display
Displays event information including name, date, venue, category, description, and registration capacity.

### 2. Search and Filtering
Students can search events by name and filter them by category or date.

### 3. Event Details
The View Details button displays additional information about a selected event.

### 4. Student Registration
Students can enter their name, student ID, email address, and select an event.

### 5. Form Validation
Required fields and email format are checked before registration.

### 6. Duplicate Registration Prevention
The system prevents the same student ID or email from registering for the same event more than once.

### 7. Event Capacity Management
Each event has a defined seat capacity. Registration is blocked when the event is full.

### 8. Registration Tracking
The number of registered students is displayed for each event.

### 9. View and Cancel Registration
Students can view their registrations using their student ID and cancel a registration.

### 10. Local Storage
Registration data is saved in the browser using Local Storage and can remain available when the page is reopened in the same browser.

## 🛠️ Technologies Used
- **HTML5:** Creates the webpage structure, event sections, and registration form.
- **CSS3:** Provides colours, layouts, cards, spacing, and responsive styling.
- **JavaScript:** Handles event searching, filtering, registration, validation, cancellation, and dynamic updates.
- **Browser Local Storage:** Stores registration data locally.

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Open the `index.html` file in a modern web browser.
3. Browse the available events.
4. Search or filter events.
5. Enter student details and select an event.
6. Register and view the registration status.
7. Use the Student ID to view or cancel a registration.

## 🧪 Testing
- Search for an existing and a non-existing event.
- Filter events by category and date.
- Submit the form with missing information.
- Enter an invalid email address.
- Try registering twice for the same event.
- Test registration when event capacity is reached.
- View and cancel a registration.
- Reload the page to check Local Storage persistence.

## ⚠️ Limitations
- This is a frontend demonstration project.
- Registration data is stored only in the current browser's Local Storage.
- Data is not shared automatically between different devices or browsers.
- There is no backend database or secure user authentication.
- The event list is currently defined in the JavaScript code.
